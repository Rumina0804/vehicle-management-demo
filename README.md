# 車両管理Webシステム（デモ版）

株式会社 道廣機工 様向け 車両管理Webシステムのデモ版です。
**Vue 3 + TypeScript + Tailwind CSS**（Vite）で構築しています。サーバーは不要で、データはすべてブラウザ内で生成・保存されます。

## 起動方法

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ に本番ビルド（型チェック込み）
npm run preview    # ビルド結果の確認
```

> 静的ホスティングに置く場合は、すべてのパスを `index.html` に返す設定（SPA フォールバック）が必要です。

## 画面一覧

| 画面 | URL | 内容 |
|---|---|---|
| ダッシュボード | `/` | 事業部切替、KPI、車両区分の内訳、修理費の推移（月次・累計／計画）、車検期限・修理費上位・最近の履歴 |
| 車両台帳一覧 | `/vehicles` | 条件検索、並び替え、ページ送り、CSV出力・CSV取込、最近の更新 |
| 車両詳細 | `/vehicles/:id` | 写真、基本情報、取得費用、車検・点検履歴、修理・整備履歴、添付資料 |
| 新規車両登録／台帳を編集 | `/vehicles/new`, `/vehicles/:id/edit` | 入力チェック付きフォーム |
| 修理・整備履歴登録 | `/maintenance/new` | 入力 → 確認 → 登録完了、負担額の合計チェック、写真、下書き保存 |
| 修理・整備履歴一覧 | `/maintenance` | 検索、CSV出力、見込の確定・車両復帰・削除 |
| 集計・分析 | `/analytics` | 決算年度／暦年／任意期間、前期間比較、月次推移、事業部・区分・車両・業者別 |
| マスタ管理 | `/masters` | 事業部・修理業者・修理箇所・車両区分 |

## デモの操作ポイント

- **権限の切り替え**：右上のユーザーメニューから「システム管理者／全社管理者／事業所利用者（福山）／閲覧専用」を切り替えると、メニュー・ボタン・編集範囲が権限に応じて変わります。
- **デモデータを初期化**：同じメニューから。登録・変更した内容を破棄し、今日の日付でデータを作り直します。
- **日付は常に「今日」基準**：車検期限・履歴・決算年度（4月始まり）は表示した日を基準に生成されるため、いつ開いても最新の状態に見えます。
- データはすべて架空のサンプルです（車両100台・8事業部・ユーザー134名・約3年分の修理・整備履歴）。

## フォルダ構成

```
src/
  types/        ドメインの型（本番のテーブル定義・APIの型の元）
  mock/         マスタとデモデータ生成（catalog.ts / generate.ts）
  stores/       Pinia ストア（db＝データ、auth＝ログイン・権限、ui＝通知など）
  utils/        日付・書式・集計・CSV
  components/   レイアウト、共通UI、グラフ、車両イラスト
  views/        各画面
```

## 本番システム（Laravel + Vue 3 + MySQL）への移行メモ

- **画面（views / components）はそのまま流用**できる構成です。データの取得・更新は `stores/db.ts` のアクションに集約しているため、ここを Laravel の API 呼び出し（axios 等）に置き換えます。
- `types/index.ts` の各型がテーブルにほぼ対応します：`divisions` / `vehicle_categories` / `vehicle_types` / `vendors` / `repair_parts` / `vehicles` / `maintenance_records` / `users` / `audit_logs` / `vehicle_events` / `budgets`。
- 権限（`stores/auth.ts` の権限マトリクス）は Laravel 側の Policy / Gate でも同じ内容をサーバー側で必ず検証してください（画面側の制御は表示のためのものです）。
- 写真・添付資料はデモではブラウザ内に縮小保存しています。本番ではストレージ（S3 等）に保存し、URL を DB に持たせます。
- ログインはデモでは省略しています（アカウント選択のみ）。本番では Laravel の認証（Sanctum 等）を使用します。

## デザイン上の補足

- モックアップの「修理費の推移」は2軸グラフ（月次の棒＋累計の折れ線）でしたが、目盛りの異なる2軸は読み違いの原因になるため、**月次の棒グラフ**と**累計（実績・計画）の折れ線**の2つに分けています。
- 各グラフには「グラフ／表」の切り替えがあり、同じ数値を表でも確認できます。
- 車両写真はデモ用に、車両タイプ別のイラスト（SVG）で表示しています。詳細画面から実際の写真を追加することもできます。
